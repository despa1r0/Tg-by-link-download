## Временная заглушка Instagram Reels

По запросу пользователя ссылки Instagram `/reel/`, `/reels/`, а также варианты
с префиксом пользователя или `/share/reel/` сразу получают сообщение о временной
недоступности Reels. Запросы к yt-dlp и proxy для этих ссылок не выполняются.
Обычные посты `/p/` продолжают обрабатываться прежним способом; доступность
каждого поста всё ещё зависит от Instagram. Заглушка определяет тип по URL,
а не по содержимому публикации. CI/CD в master по-прежнему отсутствует.

## Назначение и запуск

Telegram-бот на Python/aiogram 3 скачивает медиа по ссылкам YouTube, TikTok,
Instagram, Twitter/X и Reddit, извлекает аудио и преобразует видео в animation.
Запуск: Docker Compose или `python -m bot.main`. Для локального запуска нужны
FFmpeg и FFprobe в PATH. В Docker они устанавливаются вместе.

Лимит скачивания по умолчанию — 50 МБ. Параллелизм yt-dlp и FFmpeg ограничен.
Кэш ссылок хранится в памяти 15 минут и очищается при перезапуске.

## Исправления определения медиа

- Добавлена общая модель `_media`: `photo`, `video`, `gallery`, `carousel`,
  `mixed`, с упорядоченным списком элементов и типом каждого элемента.
- Instagram: адаптирован экстрактор yt-dlp, который раньше не представлял
  фотографии как скачиваемые форматы. Фото и видео из `carousel_media` теперь
  сохраняются вместе. Версия yt-dlp закреплена: `2026.8.19`.
- Полный результат Instagram проверяется до использования одиночного ответа
  proxy. Fallback понимает GraphQL, mobile JSON и JSON-LD. Неоднозначный
  `og:image` без подтверждения типа больше не считается фотографией; image
  redirect для reel не принимается за фото публикации.
- Twitter/X: смешанные публикации и несколько видео сохраняют все элементы
  в порядке ответа API, включая animated GIF среди других медиа.
- Reddit: добавлен разбор `gallery_data` и `media_metadata` с сохранением
  порядка; известная галерея не заменяется одной OG-обложкой при ошибке JSON.
- TikTok: фото берутся из `imagePost`; отсутствие video codec и наличие
  thumbnails больше не используются как доказательство фотогалереи.
- Произвольный playlist не считается фотогалереей. Для неподдерживаемого
  плейлиста бот предлагает прислать отдельную публикацию или видео.
- Перед отправкой проверяются сигнатуры изображений и потоки FFprobe;
  расширение файла не определяет метод Telegram. HTML/JSON вместо медиа
  отклоняются, незавершённые файлы удаляются.

## Обработчики и кэш

- Фото получают кнопку Download Photo, видео — меню video/audio/GIF,
  смешанные и однородные альбомы — общие кнопки выбора элементов.
- Смешанные альбомы отправляются группами до 10 фото/видео. Остаток из одного
  элемента отправляется отдельным методом, а не недопустимым альбомом.
- При выборе отдельных элементов используются закэшированные метаданные.
  Кнопка старого сообщения больше не берёт альбом из последней ссылки FSM.
- Проверяются срок жизни кэша, номера и диапазоны элементов. Неверные токены
  и чрезмерные диапазоны отклоняются до скачивания.
- Если один выбранный элемент не скачался, уже скачанные элементы этой
  операции удаляются; неполный альбом не выдаётся за успешный результат.

## Ограничения проверки и дальнейшая эксплуатация

- `tests/fixtures/instagram.json` — синтетические обезличенные примеры форматов
  ответов, а не сохранённые ответы реальных публикаций. Живые запросы к
  соцсетям и отправка через Telegram не выполнялись. Поэтому стабильность
  конкретных постов при блокировках и rate limit пока не подтверждена.
- Proxy, возвращающий только одиночный файл без структуры публикации, не
  позволяет доказать полноту карусели. Приоритет имеет структурированный
  результат; при недоступности всех источников бот сообщает об ошибке.
- Cookies по-прежнему могут требоваться для ограниченных публикаций Instagram.
  При обновлении yt-dlp нужно повторять тесты адаптированного экстрактора.
- Docker Engine локально не запущен; образ и production-деплой локально не
  проверялись. FFprobe отсутствует в локальном PATH: его ответы в unit-тестах
  замоканы; в Docker пакет FFmpeg включает FFprobe.
- Проверка на живых примерах single photo, reel, photo/video/mixed carousel
  остаётся эксплуатационной проверкой после запуска бота с нужным доступом.
